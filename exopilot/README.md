Chery/Omoda/iCaur/JAECOO) built on DragonPilot 0.10.0. DragonPilot remains
intact and attributed to Rick Lan; EDP-owned policy, integration, and
documentation live under `exopilot/`.

The branch starts at DragonPilot base commit
`549577a29d580ad3fa968a0db6092c91269fc6e7` (standalone history; feature-migration
origin for `EDP10 -> NGP10 -> EOP10 -> 01M -> 02M`).
See [`docs/BRANCH_CONCEPT.md`](docs/BRANCH_CONCEPT.md) for scope and
[`docs/MIGRATION_PLAN.md`](docs/MIGRATION_PLAN.md) for the staged port plan.
