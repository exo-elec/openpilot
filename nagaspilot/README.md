# NagasPilot NGP10

NGP10 is the minimized EOP10 application layer for original comma 3 hardware.
TC275 presents the target car through the upstream Tesla/OpenDBC boundary.
Every new driving output remains diagnostic or a non-controlling proposal.

Start with [the documentation index](docs/README.md). The executable feature
composition is `selfdrive/controls/lib/ngp_suite.py`; the only runtime binding
is `selfdrive/ngpshadowd.py`, which publishes `ngpState` diagnostics.
