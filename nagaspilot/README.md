# NagasPilot NGP10

NGP10 is the minimized EOP10 application layer for original comma 3 hardware.
BrownPanda presents the target car through the upstream Tesla/OpenDBC boundary.
Radar-capable BrownPanda hardware additionally enables NGP10's party-bus
Continental radar path. Every new driving output remains diagnostic or a
non-controlling proposal.

Start with [the documentation index](docs/README.md). The executable feature
composition is `selfdrive/controls/lib/ngp_suite.py`; the only runtime binding
is `selfdrive/ngp_shadowd.py`, which publishes `ngpState` diagnostics.
